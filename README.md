# Sistema de Monitoramento vitais de pacientes em Linguagem C
Projeto desenvolvido em Linguagem C utilizando conceitos de programação estruturada.

## Funcionalidades
- Registro de pacientes
- Simulação de sinais vitais
- Interação entre médico e paciente

## Conceitos utilizados
- Structs (simulando orientação a objetos)
- Ponteiros
- Modularização (.h e .c)

## Como executar:
```bash
gcc main.c pessoa.c paciente.c medico.c -o programa
./programa
